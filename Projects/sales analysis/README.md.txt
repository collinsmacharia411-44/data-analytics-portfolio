
# Sales Data Analysis Using MySQL

## Project Overview
This project analyzes sales data using MySQL to identify
revenue trends, top-performing products, category performance,
regional differences and product returns.

## Tools Used
- MySQL
- SQL
- GitHub

## Business Questions
1. Which products generate the most revenue?
2. Which countries generate the most sales?
3. Which product categories perform best?
4. How does revenue change over time?
5. How many records involve returned orders?

## SQL Skills Demonstrated
- SELECT and WHERE
- Aggregate functions
- GROUP BY and ORDER BY
- Date functions
- LIMIT
- Business-focused data analysis
